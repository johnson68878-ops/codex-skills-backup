# 第 1 週｜嵌入式架構與低功耗工作流整合

發布日期：2026-10-26。發布基準：86 個個人 Skills；本週新增 1 個，累計 87 個。

## 本週完成

- 比對 GitHub 的 86 項與本機的 62 項個人技能：34 項完全一致、52 項僅倉庫保留、28 項僅本機存在、0 項同名內容差異。
- 收錄 `embedded-systems`，涵蓋 MCU、RTOS、ISR／DMA、通訊介面、記憶體與低功耗規劃。
- 建立跨 EE／RF／ME／FW 的[嵌入式 review 檢核表](W01-EMBEDDED-REVIEW.zh-TW.md)，要求每項問題連結輸入、風險與驗證證據。
- 建立[六週導入計畫](SIX-WEEK-PLAN.zh-TW.md)、[功能分布](CAPABILITIES.zh-TW.md)與[基準比對](BASELINE-COMPARISON.zh-TW.md)。未來批次只公布範圍，本週不提前收錄。

- 修復既有 huggingface-community-evals 備份遺漏的佔位符 `.env.example`，讓乾淨下載也可符合原 manifest；未修改原有技能內容或雜湊。

## 驗證與限制

本週對新增技能執行來源、授權、檔案結構、備份雜湊與憑證樣式掃描。倉庫全部 87 項的檔案一致性另以 verification 紀錄佐證。這些檢查不代表 87 項技能的外部服務、工具與實機全部可用。MCU SDK 依使用者決定暫不安裝；尚未進行板端測試、功耗量測或產品性能驗證。

## 可直接分享的本週說明

本週啟動面向穿戴式系統架構工作的六週 AI Skills 導入計畫，先完成本機與 GitHub 技能資產的基準比對，並新增嵌入式系統工作流，將 MCU／RTOS 分工、低功耗狀態、ISR／DMA、記憶體與時序預算納入一致的架構 review 檢核。倉庫目前收錄 87 個 Skills，涵蓋硬體與嵌入式架構 16 項、品質與驗證 11 項、軟體交付與治理 24 項、資料／AI／知識工作流 15 項、技術溝通與視覺呈現 14 項，以及需求／商業／技術調研 7 項。本階段著重建立可追溯的來源、版本與驗證邊界，讓 AI 輔助工作能對應工程輸入與審查證據；本週完成的是技能整合及檢核流程，實機驗證將另依目標硬體安排。後續將逐週補上實驗設計、統計判讀、生理訊號分析與技術溝通能力。
