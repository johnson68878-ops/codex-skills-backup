## 每週交付與驗收

1. 僅將本週允許清單的技能加入 `skills/`；保留原有項目與其他使用者修改。
2. 保留上游授權與作者，記錄來源與可驗證版本；更新個人技能 manifest 的檔案數、大小與 SHA-256。
3. 更新功能分布、分類映射、本週技術應用筆記與可直接分享的繁體中文週報。
4. 執行檔案一致性檢查及適用的功能測試。未做實機測試時，明確標記為未驗證。
5. 以正常日期提交並推送 GitHub；不回填日期、不建立空提交、不一次補發未來所有批次。

- W1：MCU／RTOS 分工、喚醒與睡眠、ISR／DMA、記憶體與時序預算；建立架構 review 檢核表。MCU SDK 與實機測試未納入本次授權。
