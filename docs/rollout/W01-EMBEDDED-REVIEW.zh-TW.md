## 使用上游範例時的審查重點

- `volatile` 不提供原子性或互斥；共享資料還需考慮存取寬度、臨界區與記憶體順序。
- 單一 byte 加旗標的 UART 範例只是骨架；連續輸入可能覆寫未處理資料，產品應按吞吐量設計緩衝及溢位策略。
- Queue 傳送失敗必須處理；以實際 FreeRTOS port 檢查 stack 大小單位與中斷優先級限制。
- 暫存器、時鐘與旗標清除語意必須核對目標晶片 datasheet／errata，不能直接把示例套到其他 MCU。
